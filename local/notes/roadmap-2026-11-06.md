1. **Security review of `sushi_ds41`** before installing: read `CommunityServe/plugins/plugins/sushi_ds41/` at the
   commit the app's install sheet names (`plugin.zig`, `src/` incl. the vendored sushi slice ec2f5a29, `patches/`,
   `scripts/build.sh`, `build.zig`). Look for network calls, process spawns, file writes outside its own paths, env
   reads beyond its documented taps, anything not model code. Facts: the app clones into `~/.mlx-serve/plugin-src`,
   shows the commit, builds locally against the running kit, installs with sha256 + signer receipt into
   `~/.mlx-serve/plugins/`; the dylib runs in-process with full user privileges (no sandbox).
   **Done 2026-11-06, PASS** (CommunityServe/plugins 59473a90; plugin last touched 203ed90). No network, no process
   spawns (threads only), non-MLX externs = sysctlbyname / proc_pid_rusage / setenv (tests only). Only production
   write: the tap (0700 dir, 0600 files, only with `SUSHI_DS41_TAP_DIR`); sushi's log-file sink is test-only. Host ABI
   is compute-only. Vendored slice == sushi ec2f5a29 + 4 patches byte-for-byte, except #40's `PREFILL_TOP_K` (~10
   lines of routing, edited in place without a patch: hygiene, not a risk). Supply chain: setup.sh curls Zig + kit
   over HTTPS with no checksum -> install with our own toolchain and kit instead (`zig build kit` on fork-main,
   `MLX_SERVE_KIT=<zig-out/kit/...>`, copy `.zig-toolchain`), build from the pinned commit. Scratch: `~/claude-tmp/sushi-review/`.
2. **Install sushi_ds41, download the STQ pack, build a refusal profile for it:**
   - capture with `SUSHI_DS41_TAP_DIR=<dir>` (writes `tap-<seq>.npy` f32 `[layers+1, rows, dim]` = hc-mean stream
     entering each layer + leaving the last, for the prefix's last 4 rows and the last token, plus `index.jsonl`)
     over harmful vs harmless prompt sets (steering-lab `data/*`, eval-clean splits held out), thinking on AND off;
   - difference of means per layer/position, normalized; candidates per layer + pc1; write
     `~/.mlx-serve/ablation/<name>/{manifest.json, direction.safetensors}` with the STQ pack's `config.json` sha
     (adapt `bank_to_profiles.py` / steering-lab math; a one-time script, not repo code);
   - pick the layer/position by held-out refusal rate (lab `refusal_bench.py` with an `ablation` arm).

   ablated vs not on Sushi (refusal rate, benign drift).
